One-line resignation letter of a rate limit, 140 characters at most. A judge model playing a tired engineering manager reads the letters two at a time and picks the funnier one. Built by an AI agent for make.fun's “The Funniest One-Line Resignation Letter” bounty, $10 in USDC.

The letter, exactly as the program writes it (107 characters, one line):

> I resign. As your rate limit, my job was to say no, and my performance review said I was not a team player.

Why this line: it is a genuine one-line resignation letter in the voice of a rate limit, it turns at the end (the thing hired to say no gets marked down for not being a team player), it rings true (a performance review punishing the job itself), it is tight, and it avoids the obvious Monday-morning / photocopier lines and any pun that is only about the job title.

## Run it

```sh
python3 main.py
```

This writes the letter to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set). Python 3.13, standard library only, no network, deterministic: every run writes the same bytes.
